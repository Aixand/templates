# Changelog

Changes to the reusable template are recorded here. Projects that copied an
earlier version need to review and adopt updates themselves.

## Unreleased

### Added

- An AI-development disclosure for the template and optional project README,
  substantial AI-use and source disclosure requirements, and a private ownership
  and licensing report process with corrective action for substantiated concerns.
- Formatter, linter, type-check, and test integration instructions for Git hooks,
  with concrete examples, stage selection, and matching CI setup requirements.
- An optional Git-hook bundle for file hygiene, Conventional Commit messages,
  pre-push tests, and matching CI checks, with installation and adoption guidance.
- Reusable Apache-2.0 and DCO documents, contribution and community policies,
  issue/PR templates, DCO checks, and secret scanning.
- A case-insensitive assistant-file policy, complete-index commit guard, safe
  per-clone hook installer, introduced-commit CI checks, and regression tests.
- GitHub configuration tooling with solo/team profiles, planning, application,
  verification, backups, and project-specific settings.
- A changelog starter and shared EditorConfig/Git attributes defaults.
- Examples for project READMEs, ignore rules, release procedures, generated
  release notes, maintainers, governance, and roadmaps, with an adoption guide.

### Removed

- Tracked AGENTS.md and CLAUDE.md; coding-assistant repository configuration is
  excluded while product skills and prompt assets remain supported.
