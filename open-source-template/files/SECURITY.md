# Security policy

## Report a vulnerability privately

Report suspected vulnerabilities in {{PROJECT_NAME}} to
[corporate@aixand.org](mailto:corporate@aixand.org) with the subject
`{{PROJECT_NAME}} security report`. The project is maintained by Artificial
Intelligence Advancement Initiative Inc. If the repository offers GitHub's
private vulnerability reporting, you may use that channel instead.

Do not disclose an unpatched vulnerability in a public issue, discussion, or
pull request. For ordinary bugs and usage questions, see [SUPPORT.md](SUPPORT.md).

Include, where available:

- The affected version or source commit, operating system, and relevant setup.
- The affected component, expected security boundary, and potential impact.
- Minimal reproduction steps using synthetic data or a safe proof of concept.
- Any suggested fix, your preferred contact, and whether you want public credit.

Remove credentials and unrelated private information from reports and diagnostic
files. Ask for an appropriate transfer method before sending sensitive material
or large attachments. Do not test against systems or data without authorization.

## Supported versions

Reports are welcome for any version. Security fixes normally target the current
`main` branch and the latest stable release, if one exists. Older releases,
snapshots, and forks do not have guaranteed backports. Maintainers may ask you to
reproduce a problem on a current version. Any additional maintained release lines
will be documented here.

## Response and disclosure

Maintainers will review reports, investigate impact, and coordinate remediation
and disclosure with the reporter where practical. Timing depends on severity,
complexity, and maintainer availability; there is no guaranteed response or fix
deadline. We will handle sensitive details discreetly and share them as needed
to investigate and fix the issue. Absolute confidentiality cannot be guaranteed.

Please coordinate public disclosure so users have a reasonable opportunity to
receive a fix or mitigation. Reporter credit is optional and will be discussed
before publication. Submitting a report does not create a bounty or compensation
commitment.
