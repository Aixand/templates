# Status fixture

Read a synthetic readiness value from a command. This small example demonstrates
a complete documentation path; it does not inspect a real service.

Requires Python 3.11 or newer. Run from this example's directory, which contains
`tools/status.py`:

```sh
python3 tools/status.py
```

Expected output is `ready` and exit code zero. The command creates no files or
running services, so cleanup is unnecessary.
