# Changelog

## Unreleased

### Added

- Revision-2 workspace configuration with independent hierarchical products,
  product groups, variants, component adapters, and coordinated source identities.
- Portable artifact verification, installation planning/inspection, separate
  source origins, private/shared ownership, recoverable activation, batch request
  journals, native Windows launchers, stateless rollback, and explicit cleanup.
- Coordinated offline Python wheelhouses, SDK consumer verification, native
  multi-binary and real embedded-Python fixtures, runtime archive provisioning,
  and a pinned interpreter bootstrap for shell/PowerShell.
- Versioned product schemas, streaming operation events, release export/tag
  checks, adoption documentation, and additional native platform CI contracts.

- AI-development disclosure, substantial AI-use and source disclosure
  requirements, and private ownership/licensing reports with corrective action
  for substantiated concerns.

- A Python standard-library helper with thin Unix/PowerShell entry points,
  language-independent command hooks, and Python/Cargo package adapters.
- Versioned configuration, artifact, and selection-receipt schemas; owned Unix
  installations with recoverable activation, artifact upgrades, stateless rollback,
  explicit retention cleanup, and preservation of persistent state.
- Real Python library/tool and Cargo library/CLI/workspace fixtures, package
  consumer tests, and rejected-input/retry/install lifecycle coverage.
- CI and opt-in PyPI, crates.io, and native GitHub Release workflow examples,
  published-package confirmation adapters, and a checksum-pinned actionlint bootstrap.
- Accepted first-version/lifecycle decisions and an adoption guide distinguishing
  locally implemented behavior from remaining native-platform and publication work.
- Initial design for a common local development, build, installation, packaging,
  and publishing interface across Python, Rust/Cargo, web, and mixed projects.
- Command and release contracts and project profiles.
- An assistant-file policy with a complete-index commit guard, safe local hook
  installation, introduced-commit CI checks, and regression tests.
